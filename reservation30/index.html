이번에 바뀐 것

  • ① 예약 홈을 같은 폴더의 예약 홈 프로토타입(recurring-entry.html, Figma 10766:65699 D안)으로 바꿨습니다. CSS와 에셋은 원본에서 스크립트로 옮겨 .rh 아래로 감쌌습니다. 일반예약·"예약 시작하기"는 일반 탭으로, 시간예약은 시간 탭으로 들어갑니다.
  • ② 시간&경로 아코디언. 경로 카드와 픽업 시간 카드는 하나만 열리고, 하나가 열리면 다른 하나는 요약 한 줄로 접힙니다.
  • 대기 서비스(TADA-9812)를 걷어냈습니다. 옛 화면이라 반영하지 않습니다.

Figma에 적힌 규칙을 그대로 따른 것

보드의 가이드 메시지·해부도 주석에 적힌 동작입니다.

  • 경로 입력 → 픽업 시간 필드 열림. 휠이 열리면 경로 카드는 "경로 | 요약"으로 접히고 버튼은 "설정 완료"가 됩니다([rsrv_02] 시간 및 경로#3).
  • 픽업 시간 기본값. 처음 열 때 현재 시각의 초를 버리고 +30분, 10분 단위로 올림.
  • 오류 상태. 30분 이내면 "30분 이후부터 예약 가능", 8주를 넘기면 "최대 8주 후까지 예약 가능"을 주황(#FE4C00)으로, 선택 밴은 회색(#EFEFF1), "가장 빠른 시간으로 설정" 칩, "설정 완료" 비활성. 칩을 누르면 휠이 가장 빠른 시각으로 굴러갑니다.
  • 차량 선택에서 뒤로 오면 경로 카드가 열린 상태이고 "설정 완료"는 항상 활성.
  • 카드 등장 애니메이션. 새로 나타나는 카드는 20px 아래에서 300ms 동안 떠오르고, 사라질 때는 바로 사라집니다.
  • 미리보기. 제목 영역 절반 스크롤 시 앱바 제목, 부가 서비스 없으면 카드 제거, CTA 차종 선택 '다음'·미리보기 '예약하기', 넛지 slide-up, 하단 그림자, 요금 줄 순서.

✈️ 항공편 모드 (TADA-3746)

레일에서 출발지를 "인천공항 → 시내"로 바꾸거나 "항공편 모드로 바로 보기"를 누르세요.

  • 결정 반영. "넥스트 예약 시 100% 확정" 넛지 유지, 시간 예약 탭에서는 미노출, 프리미엄 밴은 불가 라인업(Figma "차량 선택 버튼 케이스"의 예약불가·예약불가_선택함).
  • ② 시간&경로. 출발지가 인천공항이고 일반 예약이면 안내 카드 자리에 항공편 넛지, 픽업 시간 카드 안에도 입구 링크. 시트에서 편명 자동완성 → 여유 시간 칩 → 카드가 "예상 픽업"으로 바뀝니다.
  • ③ 차량 선택 상단 알약이 "예상 22:25 · LJ082"로, ④ 미리보기는 제목이 예상 픽업 시각으로 바뀌고 경로 아래 항공편 카드와 결항·무료 취소·늦은 배차 안내가 들어갑니다.

Figma에 없어서 제가 정한 것

  • 경로 검색은 생략. Figma는 "어디로 가세요?" 빈 경로에서 시작하지만, 프로토는 경로가 채워진 상태로 들어갑니다.
  • 맞춤예약·정기예약 아이콘은 이 프로토 범위 밖이라 안내만 띄웁니다. 다시 예약하기 카드·쿠폰·FAQ는 누를 수 없습니다.
  • 항공편 모드의 안내 카드 자리 우선순위. 경유지가 없으면 항공편 넛지, 있으면 기존 시간 예약 안내. 넛지·시트·불가 사유 문구, ✈️ 아이콘, 편명·도착 시각은 더미이고 여유 시간 30분~1시간 30분 범위도 임의입니다.
  • 플러스·프리미엄 밴 요금·라인업, 경유지를 켰을 때의 "1시간 6분 예상"은 더미입니다.
