타다팟 IA 맵과 콘서트 클릭 프로토

[1] B2C 셔틀 방향성 PRD 초안 기준. 왼쪽 맵의 칸을 누르면 오른쪽 폰에 그 화면이 뜨고, 폰 안에서 누르면 맵의 현재 위치가 따라와요. 이번 프로토는 콘서트 리더와 멤버의 웹 흐름만 만들었고 학원은 맵에만 있어요.

새로 만들어야 함 기존 코드 재사용 (미미르 확인) v2 검토, 화면 없음 이번 프로토 범위 밖

1. 팟 찾기 경로

첫 버전은 초대 링크로만 참여. 맵에는 v2 자리만 둔다.

  • 2024 택시팟: "택시팟 찾기"를 둘러보기로 오해해 자기도 모르게 총대가 된 오조작이 여러 건.
  • 모빈의 그룹 합승과 그룹 주문은 모두 링크 초대형: Grab Group Ride, Wolt, Swiggy. 공개 목록형은 BlaBlaCar처럼 운전자가 좌석을 파는 모델뿐.
  • PRD의 안전 가치가 "아는 사람끼리 타는 팟". 모르는 사람 매칭은 반반택시처럼 실명 가입과 동성 매칭 같은 별도 장치가 필요했다.
  • 대신 총대 부담을 낮춘다: 랜딩에서 "팟 만들기(내가 리더)"와 "초대 링크를 받았어요"를 처음부터 갈라 둔다.

2. 콘서트 미성년자

멤버 결제 단계에 "보호자에게 결제 부탁하기" 분기를 둔다.

  • 현행 코드: 정회원 가입은 만 19세 미만을 KCP 인증 전에 막는다. 비회원 호출 웹은 문자 인증만 하고 나이를 보지 않는다 (미미르, 2026-10-19).
  • 2024 택시팟: 웹 신청은 됐지만 미성년자가 앱 로그인과 결제를 못 해 CS로 처리.
  • 선례: Uber 가족 프로필은 보호자가 초대하고 결제하며 이동을 따라본다. Grab for Family는 링크 초대와 관리자 결제.
  • 학원의 부모 결제와 자녀 탑승이 같은 구조라 부품을 함께 쓴다. 미성년 단독 탑승은 법무 확인 전.

3. 프로토 범위

맵은 콘서트와 학원 둘 다, 클릭 화면은 콘서트 리더와 멤버 웹만.

  • PRD에서 미지수가 가장 큰 곳이 콘서트다: 웹 참여, 각자 가승인, 인원 미달 결정.
  • 학원은 PRD 표현대로 "사실상 정기 예약 + 다중 하차"이고, 결석·노쇼 경계와 고정 금액은 인터뷰 대기, 어린이 통학 규정은 법무 대기.
  • 공통 뼈대(팟, 멤버, 각자 결제)는 맵에서 학원 줄과 맞물리게 그려 두었다.

4. IA와 클릭 프로토의 관계

한 페이지에 두되 층은 나눈다. 맵은 구조, 폰은 과업.

  • NN/g: 사이트맵은 논의에 필요한 정도만 담는 공유용 구조도이고, 과업 경로와 사용성 검증은 플로우와 프로토가 맡는다.
  • 그래서 맵 칸은 화면 단위로만 두고, 상태 변화(인원, 결제 상태)는 폰 아래 설정으로 바꿔 본다.

금액과 날짜는 PRD 예시값이에요 (1인 20,000원 + 거리 금액, 고양 → 서울 도심 정가 약 71,000원, 리더 혜택 3명 3,000원부터). 모집 마감, 대기 상한, 취소 수수료는 PRD에서 아직 정하지 않았어요.
