정기예약 진입점 확대하기 — 예약 홈 비교 프로토타입

TADA-9482 · 예약 홈 10375:113099 기준 · 네 가지 진입점 배치를 같은 조건에서 비교합니다.

문제 — 정기예약을 만들 수 있는 유일한 진입점은 예약 미리보기 화면의 배너뿐이고, 거기 닿으려면 6단계 + 노출조건 4개를 모두 통과해야 합니다. 배너를 클릭한 582명 중 1시간 내 정기예약을 만든 사람은 40명(6.9%). 그런데 현재 예약 홈의 방법 카드는 가로 캐러셀이라, 세 번째 카드(맞춤)조차 화면에 6px만 걸칩니다 — 네 번째로 정기를 붙이면 그대로 안 보입니다.

읽는 법 · 프로토타입 주석

  • 판정 기준 — 스크롤 0 상태에서 정기 카드가 하단 ‘예약 시작하기’ 시트 윗선(콘텐츠 상단부터 595px) 안에 들어오면 보임, 걸치면 일부, 넘어가면 안 보임. 시트에 가려지는 영역은 실제로 안 보이므로 제외했습니다.
  • ‘작성 중’ 건수가 최대 변수입니다. 다시 예약하기 섹션이 정기 카드를 그대로 아래로 밀어내므로, 0건 / 2건을 번갈아 보면 각 안의 내구성이 드러납니다.
  • 정기 카드 카피 “매주 같은 시간에 반복 예약해요”는 제안입니다. Figma 탐색안에는 맞춤 예약에서 복사된 “일반 예약, 시간 예약 모두 가능해요”가 그대로 들어가 있습니다. PRD의 씬 데이터(평일 6~9시 출퇴근·등교, 반복 요일 상위 패턴 전부 평일)를 근거로 바꿨습니다.
  • 정기 썸네일은 기존 ‘정기예약 유도 배너’의 illust_calendar를 그대로 가져왔습니다. 다른 카드가 3D 렌더 썸네일이라 톤이 맞지 않습니다 — 실제 핸드오프 전에 같은 스타일의 썸네일이 필요합니다.
  • B안 아이콘은 Figma 탐색안에 후기 프로필 아바타가 임시로 꽂혀 있어, 서비스 썸네일을 원형에 넣어 대체했습니다.
  • A안에는 ‘예약 방법’ 섹션 헤더가 없습니다 — Figma 탐색안 그대로 두었습니다. 카드만 덩그러니 놓이면 네 개가 무엇의 목록인지 설명이 사라지므로, 확정 전에 의도인지 확인이 필요합니다.
  • B안에 쿠폰 배너를 넣었습니다 — Figma 탐색안에는 없지만, 네 안을 같은 콘텐츠로 비교하려고 추가했습니다.
  • A안 ‘다시 예약하기’ 라벨이 Figma에서 12sp로 잡혀 있는데(as-is 16sp, B안 15sp) 실수로 보여 15sp로 통일했습니다.
  • 범위 — 홈 화면까지입니다. 정기 카드를 누르면 하이라이트 + 토스트만 뜨고, 그 뒤 설명 시트 → 시간·경로 → 차종 → 반복 주기 → 일정 조율 → 정기 미리보기는 담지 않았습니다.
  • 수치·간격·색은 Figma 실측값입니다 (프레임 360폭, 캐러셀 카드 160×152 / gap 10 / 좌패딩 24, A안 그리드 카드 151×86, 하단 시트 110 + 탭바 63).
