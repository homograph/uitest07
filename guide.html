통합 넛지 · 밴드 ↔ 플로팅 new/info_bar

차량 선택 하단의 수요·혜택 넛지. 진입 시 플로팅으로 강조 → 상호작용 시 띠배너로 도킹. 요금 블록은 손대지 않음.
새 탭 ↗
좌측은 실제 index.html. 프로토타입 우상단 ⚙에서 넛지(없음/수요/무료취소)×보장(없음/공항·넥스트/프리미엄밴)을 조합해 모든 케이스를 볼 수 있습니다.

01개요

해당 탑승일·차량 조건에 맞는 넛지를 하단에 노출한다. 진입 순간엔 플로팅으로 강조하고, 사용자가 스크롤 등 상호작용을 하면 띠배너로 도킹해 방해를 최소화한다.

  • 요금 블록 불변 — 예상 요금·서지(↗)·할인(취소선)·다음 버튼 영역은 넛지와 무관하게 그대로. 넛지는 요금 바 위에서만 동작.
  • 메시지 종류 — 넛지: 🔥 수요 몰림(FOMO) · 무료 취소 / 보장: ⚡ 100% 예약 확정(공항·넥스트, 프리미엄 밴).
  • 넛지는 단일 — 수요/무료취소 중 하나만. ⚡ 보장은 넛지와 공존(도킹 시 한 줄 병합).

02상태 (States)

플로팅 (강조)

진입 강조용. 90° 그라데이션 #0094F9→#32A2FA, 흰 텍스트, 쉬머. 좌우 마진 16·요금바 위 16 띄움, 라운드 8, 옅은 단일 섀도우.

🔥 이 날은 예약이 평소 대비 2배 몰리고 있어요
넛지 풀 문구 1개만 — ⚡ 보장은 플로팅에 노출하지 않음

띠배너 (도킹)

풀블리드 blue-50 #E2F2FE 스트립, 12px/Medium(확정 Bold), 패딩 8·24. 넛지 단독은 풀 문구, ⚡와 함께면 한 줄 병합. 문구가 길면 2줄 도킹(세로 중앙).

넛지 단독 = 풀 문구
예약 2배 몰림 ⚡ 넥스트 예약 시 100% 확정
넛지+⚡ 병합 = 넛지 축약 + ⚡ 풀

넛지·⚡ 모두 없으면 미표시. ⚡만 있으면 띠배너만(플로팅 없음).

04강조 · 아이콘 규칙

대상규칙
수요 2배단독·플로팅에서만 blue-600 강조. 병합 띠배너에선 일반(파란 강조 중복 방지 — 병합의 유일한 파랑은 ⚡ 쪽).
⚡ 100% 확정 / 100% 예약 확정항상 blue-600 강조.
무료취소 무료 취소다크 볼드(gray-800) — 파랑 아님.
이모지수요=🔥, 보장=⚡. 무료취소는 이모지 없음. 병합 띠배너에선 넛지 이모지를 빼고 ⚡ 하나만(이모지 중복 방지). 플로팅·단독 띠배너는 넛지 이모지 유지.

05인터랙션 · 모션

  • 문구는 서버에서 내려옴 — 각 상태(플로팅/띠배너) 문구를 서버가 완성해 내려줌. 클라는 표시만 (병합 조합을 클라에서 하지 않음).
  • 생성(진입 · 데이터 새로고침) — 배너가 바텀바(다음 버튼) 뒤(z 아래)에서 +y로 올라와 안착. 넛지(플로팅 가능)면 플로팅으로, ⚡만이면 띠배너로 올라옴. 각자 최종 형태의 서버 문구를 처음부터 표시 → 자동 전환 중 글씨가 바뀌지 않음(깜빡임 0).
  • 스크롤 → 도킹 — 플로팅이 제자리에서 띠배너로 모프(띠배너 문구로). 첫 스크롤 1회.
  • 띠배너 탭 → 플로팅 — 도킹의 역(제자리 모프). 사용자가 유발하므로 문구가 바뀌어도 자연스러움. 스크롤 우선: 펼치는 모프 도중/직후 스크롤하면 즉시 그 자리에서 부드럽게 띠배너로 되돌아 도킹(대기 데드존 없음).
  • 차종 변경 = 데이터 새로고침 — 이전 배너 즉시 사라지고 새 배너가 바 뒤에서 띠배너로 재생성(올라옴). ⚡(보장)만 바뀌고 🔥수요는 유지. 재플로팅 없음.
  • 예약확인(미리보기) — 진입 시점 형태로 따라옴. 넛지 있으면 그 띠배너도 탭 → 플로팅. ⚡ 단독(플로팅 조건 미충족)은 탭 무반응, 넛지·⚡ 모두 없으면 미표시.
  • 토스트 — 뜨면 플로팅 넛지는 띠배너로 도킹되고, 토스트는 도킹된 띠배너 위 10px에 뜬다(띠배너까지 하단 컨테이너 포함 → 가리지 않음). 띠배너 높이는 1줄/2줄 가변이라 표시 직전 실측해 얹음. 띠배너 없으면 바텀바 위 10px.
규칙 한 줄: 생성 = 바 뒤에서 올라옴(transform translateY) / 세션 중 전환(접기·펼치기) = 제자리 모프(left/right/bottom/radius/shadow). 둘 다 0.42s cubic-bezier(.4,0,.2,1).

배너 z-index는 요금바(다음 버튼)보다 아래 → 바 뒤에서 emerge. 플로팅은 위쪽에 뜨므로 상승 시작 y가 띠배너보다 큼(플로팅 ~64 / 띠배너 ~46). 플로팅 쉬머: 흰 하이라이트 좌→우 sweep(~155px, α .25). 전이 시작은 rAF 대신 setTimeout(백그라운드 탭 rAF 정지 대비).

06구현 · 네이티브 참조

생성(바 뒤에서 상승) · 도킹 · 탭 · 재생성(차종 변경) + 서버 문구 렌더. 디자인·애니메이션·인터랙션 기준 최신 코드입니다. 문구·병합·강조는 서버에서 완성해 내려주고 클라는 표시만 하며, 섀도우는 옅은 단일 navy .10(폐기된 글로우 아님)입니다.

SwiftUI
enum NudgeForm { case floating, band }        // 플로팅(강조) / 띠배너(도킹)

// 서버가 상태별 완성 문구를 내려줌 (병합·강조 조합은 서버에서)
struct BannerData: Equatable {
  let floatingText: AttributedString?   // 플로팅 문구(넛지). nil = 플로팅 불가(⚡만)
  let bandText: AttributedString?       // 띠배너 문구(넛지축약+⚡ 병합 / 넛지 / ⚡). nil = 미표시
  var floatable: Bool { floatingText != nil }
}

struct NudgeBar: View {
  let data: BannerData
  @State private var form: NudgeForm = .band
  @State private var riseY: CGFloat = 0        // 생성 시 바 뒤(+y)에서 올라옴

  var body: some View {
    if let text = (form == .floating ? data.floatingText : data.bandText) {   // 없으면 미표시
      Text(text)
        .font(.system(size: form == .floating ? 15 : 12, weight: form == .floating ? .regular : .medium))
        .foregroundColor(form == .floating ? .white : Color(hex: "#383D4F"))
        .lineLimit(form == .floating ? 1 : 2)                       // 띠배너: 길면 2줄 도킹
        .multilineTextAlignment(.center)
        .padding(.horizontal, form == .floating ? 18 : 24)         // 도킹 좌우 24
        .padding(.vertical,   form == .floating ? 12 : 8)          // 도킹 상하 8
        .frame(maxWidth: .infinity)
        .background(bg(for: form))                       // 그라데이션 / blue-50 (+쉬머)
        .clipShape(RoundedRectangle(cornerRadius: form == .floating ? 8 : 0))
        // 옅은 단일 섀도우 (navy .10) — 폐기된 파란 글로우 아님
        .shadow(color: Color(hex: "#19254D").opacity(form == .floating ? 0.10 : 0), radius: 6, y: 4)
        .padding(.horizontal, form == .floating ? 16 : 0)          // 좌우 마진
        .offset(y: riseY)                                          // 생성 애니: 바텀바보다 낮은 zIndex → 바 뒤에서 상승
        .animation(.timingCurve(0.4, 0, 0.2, 1, duration: 0.42), value: form)
        .animation(.timingCurve(0.4, 0, 0.2, 1, duration: 0.42), value: riseY)
        .onTapGesture { if form == .band, data.floatable { form = .floating } }   // 띠배너 탭 → 플로팅
        .onAppear { create() }                                    // 진입 = 생성
        .onChange(of: data) { _ in create() }                     // 데이터 새로고침(차종 변경 등) = 재생성
    }
  }

  // 생성(진입·새로고침): 최종 형태로 세팅 후 바 뒤에서 +y → 0 으로 상승·안착
  private func create() {
    form  = data.floatable ? .floating : .band            // 넛지 → 플로팅 / ⚡만 → 띠배너
    riseY = form == .floating ? 64 : 46                   // 시작 오프셋(바 뒤)
    withAnimation { riseY = 0 }                           // 안착
  }
}
// zIndex: 배너 < 바텀바(다음 버튼) → 바 뒤에서 emerge. bg(for:)는 쉬머 오버레이 포함.
// 스크롤 → form = .band (도킹 모프). 예약확인 화면도 동일 컴포넌트: 넛지면 탭 → 플로팅.
// 차종 변경 = 데이터 새로고침 → BannerData 교체(⚡만 갱신, 🔥수요 유지) → create()로 띠배너 재생성(재플로팅 없음).
// ⚠️ 문구·강조·병합은 서버 문자열(AttributedString) 그대로 렌더 — 클라에서 조합하지 않음.
Jetpack Compose
enum class NudgeForm { Floating, Band }

// 서버가 상태별 완성 문구를 내려줌
data class BannerData(val floatingText: AnnotatedString?, val bandText: AnnotatedString?) {
  val floatable get() = floatingText != null
}

@Composable
fun NudgeBar(data: BannerData) {
  // 생성(진입/새로고침): 넛지면 플로팅, ⚡만이면 띠배너. data 바뀌면(remember key) 재생성.
  var form by remember(data) { mutableStateOf(if (data.floatable) NudgeForm.Floating else NudgeForm.Band) }
  val floating = form == NudgeForm.Floating
  val text = (if (floating) data.floatingText else data.bandText) ?: return   // 없으면 미표시

  val e = CubicBezierEasing(0.4f, 0f, 0.2f, 1f)
  // 생성 애니: 바텀바 뒤(+y)에서 0 으로 상승 (zIndex < 바텀바)
  var risen by remember(data) { mutableStateOf(false) }
  val riseY by animateDpAsState(if (risen) 0.dp else if (floating) 64.dp else 46.dp, tween(420, easing = e))
  LaunchedEffect(data) { risen = true }

  val side   by animateDpAsState(if (floating) 16.dp else 0.dp, tween(420, easing = e))
  val radius by animateDpAsState(if (floating) 8.dp  else 0.dp, tween(420, easing = e))
  val elev   by animateDpAsState(if (floating) 6.dp  else 0.dp, tween(420, easing = e))

  Row(
    Modifier
      .offset(y = riseY)                                                  // 바 뒤에서 올라옴
      .padding(horizontal = side)
      .fillMaxWidth()
      // 옅은 단일 섀도우 (navy .10) — 글로우 아님
      .shadow(elev, RoundedCornerShape(radius), spotColor = Color(0xFF19254D).copy(alpha = .10f))
      .clip(RoundedCornerShape(radius))
      .background(
        if (floating) Brush.horizontalGradient(listOf(Color(0xFF0094F9), Color(0xFF32A2FA)))
        else SolidColor(Color(0xFFE2F2FE))
      )
      .then(if (floating) Modifier.shimmer() else Modifier)               // 쉬머
      .clickable(enabled = !floating && data.floatable) { form = NudgeForm.Floating }  // 탭 → 플로팅
      .padding(horizontal = if (floating) 18.dp else 24.dp,      // 도킹 좌우 24
               vertical   = if (floating) 12.dp else 8.dp),      // 도킹 상하 8
    horizontalArrangement = Arrangement.Center
  ) {
    Text(text, fontSize = if (floating) 15.sp else 12.sp,
      fontWeight = if (floating) FontWeight.Normal else FontWeight.Medium,
      maxLines = if (floating) 1 else 2, textAlign = TextAlign.Center,  // 띠배너: 길면 2줄
      color = if (floating) Color.White else Color(0xFF383D4F))
  }
}
// 스크롤 → form = Band(도킹). 예약확인 화면도 동일 컴포넌트: 넛지면 탭 → 플로팅.
// 차종·데이터 변경 → data 교체(⚡만 갱신, 🔥수요 유지) → remember(data) 리셋 → 재생성(바 뒤에서 상승, 재플로팅 없음).
// ⚠️ floatingText/bandText 는 서버 문자열(강조·병합 포함) 그대로 — 클라 조합 없음.

// 생성(진입·새로고침): 바 뒤(+y)에서 최종 형태로 올라와 안착
function rise(intoFloating){
  bar.classList.toggle('floating', intoFloating);
  ibtext.innerHTML = intoFloating ? data.floatingText : data.bandText;   // 서버 문구
  bar.style.visibility = 'visible'; bar.style.opacity = '1';
  bar.style.transition = 'none';
  bar.style.transform  = `translateY(${intoFloating ? 64 : 46}px)`;      // 바 뒤 시작
  void bar.offsetWidth;                                                  // reflow
  bar.style.transition = 'transform .42s var(--e)';
  bar.style.transform  = 'translateY(0)';                                // 상승·안착
}
// 진입: rise(floatable) — 넛지면 플로팅으로, ⚡만이면 띠배너로 올라옴
// 스크롤 → 제자리 모프로 band(setForm(false)) / 띠배너 탭 → 제자리 모프로 floating
